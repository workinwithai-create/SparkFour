# SparkFour

Four-bar live spark desk for bedroom producers and AI-music finishers. Live FluidR3 chairs add hat patterns, snare ghosts, bass fills, and piano stabs so a static loop has life and the track can finish.

Distinct from AccentFour, DriveFour, PulseFour, LockFour, MotionEight.

- BPM 60–180, key selector, 4-chord entry.
- Live changes apply on the next step.
- Grid-perfect 48 kHz 24-bit stereo WAV + matching MIDI.
- First downbeat at sample 0. Seamless loop (tail folded).
- Samples pinned to PreEight commit SHA.
- Free. No license gate required for this MVP.

## Acceptance

Engine follows WorkinWithAI rules 1–4 and 5–8. Exports at 92 BPM / 8 bars would be exact length (use 4 bars here). No Math.random in export path. No @main. Voices match samples.

Deployed on Vercel team release-forge.
